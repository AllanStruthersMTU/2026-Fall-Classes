\begin{frame}{Exam One}
The first exam covers tanks, linear first-order equations, separable ODEs, and first-order constant-coefficient linear systems.
  \begin{itemize}
  	\item This includes $y_c$, $y_p$, and initial conditions.
  	\item The exam will be like HW (with simpler boxes) stuck together.
  	\item Four questions, on both sides of two sheets of paper, totaling 50 points.
  	\item You can write anything you want on a notecard up to $4\times6$ inches. 
  	\item The exam is in class on November 5.
  	\item We finish exam material October 29.
  	\item Monday, Tuesday, and Wednesday mostly review with some new material.

  \end{itemize}

The exam is intended to be very predictable.
\end{frame}
